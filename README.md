# Robinson Vercel MCP

A hosted MCP server that lets Chris Robinson's AI agents build on and run his Vercel teams safely — previews per branch,
deployments, promotions and rollbacks, environment variables, domains and DNS, security, logs, team members, tokens and
billing — for every project, with Appliance Desk as the first. Production changes and purchases always ask first,
secrets never pass through an AI, and results stay small so agents don't burn their context. It follows the Robinson Tool
Contract, so Robinson's Toolkit (the hub) can offer it alongside Chris's other servers, but it works fully on its own.

**Status:** plan only; no code yet. Start at [`docs/START-HERE.md`](docs/START-HERE.md). AI agents: read
[`AGENTS.md`](AGENTS.md) first.
