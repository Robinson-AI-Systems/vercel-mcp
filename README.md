# Robinson Vercel MCP

A hosted MCP server that lets Chris Robinson's AI agents build on and run his Vercel teams safely — previews,
deployments, releases, environment variables, domains, security, logs, members, tokens and billing — with production
changes and purchases always asking first, and no secret ever passing through an AI. It follows the Robinson Tool
Contract but works fully on its own.

**Status (2026-10-13):** independently hosted on Vercel with an initialized dedicated Neon schema and an encrypted, verified, team-scoped Robinson AI Systems credential. The public RTC contract and OAuth discovery respond from the deployed `live` revision, and production operations and autonomous spending are disabled. **Genuine authenticated custom MCP, connected D-2 Vercel provider reads, RTC direct/relay/Sandbox, and revocation acceptance remain unverified**; deployment READY and public metadata are not substitutes.
