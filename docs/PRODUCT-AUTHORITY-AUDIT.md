## Classification and completion vocabulary

- **DEV** = development/acceptance operating rule; retain for coding agents but exclude from product permission decisions.
- **SECURITY** = genuine provider/identity/scope/tenant/fraud/transport/irreversibility safeguard; retain or strengthen.
- **USER POLICY** = legitimately configurable, independently authorized user/organization delegation.
- **DEFECT** = end-user feature improperly limited by developer-only assumptions, or missing provider-supported execution.
- Status: **FIX IN PR #219** means implemented source candidate, still awaiting exact-head checks, review, merge and deployed proof; **OPEN** remains engineering/acceptance debt; **PRESERVE** means the security restriction remains appropriate. No source status implies production acceptance.
