## What was built

- `src/vercel/operations.js`: 12 new pinned operations (the 13th, project-domain list,
  was already pinned and is reused).
- `src/tools/domains.js`: the 11 tools. Reads resolve/verify team and project ownership
  through the same helpers other tools use (`readProvider`, `projectContext`); project-scoped
  connections are refused team-domain tools. Writes are `defineWrite` operations with
  `production()` / `targets()` declarations matching the catalog Safety marks (no `$`, `A`
  or `1x` marks, so no spend/access/secret declarations), `outsideApp` confirmation,
  full-profile enforcement for F tools, everyday-or-full for E tools, `validateRequest`
  against the pinned snapshot in every `before()`, pre-dispatch state re-checks and
  independent read-back in every `verify()`.
- Production classification per BATCH-N N1: team-domain writes are always production;
  project-domain writes use `domainIsProduction` — production unless the domain is tied
  to a branch or a non-production custom environment. Attach with a `gitBranch` therefore
  applies on a preview connection; attach without one is refused there.
- `vercel_domain_remove_from_team` (BATCH-N N6) enumerates aliases for the domain plus
  every team project's domain list (single bounded page; a paginated team refuses rather
  than claiming completeness). While anything uses the domain, dry-run previews name the
  users and refuse with that list, and confirmation is refused before any DELETE.
- `vercel_domain_attach_to_project` (BATCH-N N3) carries the `vercel_domain_check_config`
  output in the result `receipt` after the attach read-back.
- `vercel_domain_update` supports exactly one change per call: move-out to another team
  (`destination`) or an update (`zone` and/or `echMode`). Move-out is verified by domain
  absence on this team; zone-only updates report `confirmed: null` because the GET
  endpoint does not return the zone flag.
- `src/tools/index.js`: `domainsTools` registered (123 tools total).
- `tests/unit/registry.test.js`: pinned lists updated (112 → 123 names; 7 new guarded writes).
- `src/tools/meta.js` + `tests/unit/meta-dispatch.test.js`: `vercel_batch` preflight now
  refuses any call named `vercel_call` before any call runs (a delegate may not be batched;
  batches contain direct read tools only). Direct `vercel_call` behaviour is unchanged.
- `docs/TOOL-CATALOG.md`: profile/safety corrections only, code authoritative — nine
  Prof E → F, `vercel_shared_env_set` Prof F → E, `vercel_disable_production` Safety
  P → C, `vercel_create_pass` "24h" → "1–720h, default 24h". No rows added, removed or
  renamed; no section counts or totals changed.
