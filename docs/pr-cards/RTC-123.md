# RTC #123 — Bounded result-handle pagination

## Drift A
The existing stored result can be 1 MiB but the RTC HTTPS handle endpoint returned all records at once, violating RTC 1's default result ceiling. Use the existing owner/account/expiry DB gate and prepareResult shaping. No changes to stored schema, OAuth, provider calls or write interfaces.

## Acceptance
- Query page 0..10000, limit 1..20, fields and detail strictly validated.
- List bodies and raw single objects returned as bounded records with count/next/hasMore metadata.
- Strip secrets before field projection, verify byte length of final JSON envelope ≤8 KiB and refuse oversized rows without truncation.
- Invalid selector, cross-pass and expired handle never disclose body; no regression to RTC direct/Hub tests.
- Exact-head check, unit, db, emulate, aggregate ci and release-policy.
