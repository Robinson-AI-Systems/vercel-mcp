## Build contract
- Provider-neutral `compact(value)` in `src/core/util.js`: recursive hidden fields, credential-shaped text, Denver ms timestamps, dollar display alongside integer cents. Fail on cycles, excessive depth and responses >8 KB rather than silently truncate.
- Vercel `shapeVercelResult` and `shapeMcpResult` in `src/vercel/shape.js`: production banner; sanitize text-encoded JSON before leaving the MCP boundary.
- `resolveVercelInput` accepts exactly one of plain non-credential value, scoped/consumed `pendingInputId` or bounded random server `generate`; secret fields never accept a plain value.
- `issueVercelSecret` uses preexisting encrypted one-time store and returns only a setup-page reference; `hiddenChangeSummary` never stores incoming values.
- Existing `write-preflight.safeShape` enforces generic redaction even with an identity caller shaper. No new Vercel REST operations.
