## B-8a implementation (#24)
- New account-scoped `createDb().listAccountConnections` and `listRecentChanges` return bounded safe columns; no before/after/token hashes, SQL values parameterized and tenant verified.
- New `vercel_list_connections`, `vercel_recent_changes` read tools in `src/tools/observability.js`; both usable in read_only profile and never mutate provider resources.
- New `vercel_where_is_setting` with a safe dashboard-map for production branch, spend management, cron runs/settings, security two-step, deployment previews/ignored builds and preview protection; unknown settings are clearly marked as unverified.
- `vercel_whoami` warns when the stored Vercel token approaches expiry within fourteen days, without returning ciphertext.
- `tests/unit/account-observability.test.js`: scoped metadata, no credential/audit snapshots, guided vs unknown behavior, read-only classification.
- `tests/db/account-observability.test.js`: isolated disposable Postgres proof of tenant isolation, bounded SQL selections, hidden dry-run previews and filters.
- Run `npm run check`, `npm test`, `npm run test:db`; all five exact-head CI checks must pass. No live token needed.
