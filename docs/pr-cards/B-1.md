## Build contract
- `src/core/write.js`: `defineWrite` with required `production()`, `targets()`, dry-run preview, explicit confirmation, read-back verified/false/unknown, durable request identity, and no direct write call before guards pass. Each write has `before`, `apply`, `verify`, `inverse` (if reversible), declarations and safe outputs.
- `src/vercel/production.js`: pure production classification functions for deployment, environment, domains and live projects. Unknown remains high-risk.
- `src/vercel/spend.js`: cents normalization, USD rendering, spend-limit preflight, no unverified priced actions and no implicit purchase.
- `tests/helpers/write-contract.js` and `tests/unit/write-contract.test.js`: eight contract checks using fake write operations, including replay, read-back and restrictive profiles/production/spend protections.
