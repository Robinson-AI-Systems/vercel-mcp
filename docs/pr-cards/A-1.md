## Tests

- `tests/unit/fake-vercel.test.js`: path patterns with parameters; query and body recorded; token never recorded;
  configured 429 has Vercel's `rate_limited` body shape; unmatched call fails.
- `tests/unit/registry.test.js`: duplicate tool names throw; a tool without a handler throws.
- `tests/unit/check-secrets.test.js`: a planted real-shaped `vcp_` token in a temp file fails; `vcp_FAKE…` passes.
- `tests/db/contract.test.js`: contract runs on throwaway Postgres.
- `tests/emulate/ping.test.js`: `GET /v2/user` and `GET /v10/projects?limit=1` against `emulate` return JSON.
- Added: `tests/unit/checks.test.js` (check-writes, check-budgets, check-core-imports, check-catalog, check-docs-updated
