## Scope

Two read workflows in `src/tools/workflow-insights.js`, completing
Batch W (registry 239 of 241 after this card):

- **`vercel_workflow_cost_check`** (O audience; read profiles per the
  catalog) — description `{project?, from?, to?}`. Composes
  `vercel_billing_summary` and `vercel_billing_list_charges` for the
  window (month-to-date by default, the billing tools' own default),
  `vercel_deploy_list` for builds counted by day and branch (paged
  under the 45-second budget, truncation stated), and
  `vercel_drain_list`. Target: the covering stored profile's
  `cost_target_cents` when a project is named and profiled, otherwise
  the billing summary's own stored target. Every cost driver and
  every suggestion is tied to a charge actually present in the
  window's FOCUS rows — never generic boilerplate.
- **`vercel_workflow_security_audit`** (O audience) — description
  `{project}`. Sections, each `ok` / `needs_attention` (reasons) /
  `not_readable` (reason): deployment protection
  (`vercel_protection_get`), bypass secrets
  (`vercel_protection_list_bypass`; any secret older than 90 days is
  flagged with its age), firewall (`vercel_firewall_get`), variables
  (`vercel_env_list`: Secret-kind inventory, and `NEXT_PUBLIC_*`
  names matching KEY/SECRET/TOKEN/PASSWORD/PASSWD/PRIVATE/CREDENTIAL
  flagged as secrets shipped to the browser), access
  (`vercel_project_list_members` + `vercel_member_list`, with roles).

## Verdicts recorded on this card

- **W6-C1 (suggestions discipline):** a lowering suggestion is
  emitted only when its triggering charge is present in the window —
  drains charges → the drain list is named; sandbox charges →
  sandbox minutes are named; a service in the top drivers is named
  with its own cents. No charge, no suggestion.
- **W6-C2 (protection judgement):** the protection section is
  `needs_attention` when Vercel Authentication is disabled for
  production deployments (deploymentType not covering production),
  stated in those words; it is `ok` when authentication covers all
  deployments or password protection is enabled. The judgement uses
  only the fields `vercel_protection_get` actually returns.
