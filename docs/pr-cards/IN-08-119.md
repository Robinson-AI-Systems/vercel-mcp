# IN-08 #119 — revalidate price immediately before charged dispatch

## Drift A

A $0 initial declaration may become priced. The existing one-use owner ledger is not a substitute for a fresh provider-source check.

- Reject provider pricing read failures and unknown changed charges, release only definitely undispatched replay claims.
