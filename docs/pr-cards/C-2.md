## Ordered requirements
1. Register `vercel_search_tools` and `vercel_describe_tool` as scoped read tools with filtered names, schemas and safety marks, no credential/account enumeration.
2. Catalog lists all profile-eligible tools; compact lists only meta tools, `vercel_whoami`, future workflow/API search names only when registered. Search reveals available tools but no direct write elevation.
3. Implement `vercel_call(name,args)` using the identical profile + guarded dispatch and owner approval boundary as direct MCP, preserving result wrapping and replay protection.
4. Implement `vercel_batch(calls[≤10])` serially or concurrently only for read-only eligible tools; any attempted write refuses the entire batch preflight, zero handlers invoked.
5. Enforce <5000 compact and <20000 everyday catalog with pinned tokenizer, <1500 each schema and ≤160 descriptions; planted over-limit failures tested.
