## Build contract

| File | Contract |
|---|---|
| src/vercel/client.js | Exports VERCEL_API_BASE, OPENAPI_SNAPSHOT, makeVercelClient({ token, account, fetchImpl?, baseUrl? }), and deterministic requestKey(ctx, tool, args). Production base is fixed to https://api.vercel.com; tests inject fetch/base URL. |
| src/vercel/operations.js | Exports OPS as { id: { method, path } }; every operation used is present in the exact vendored snapshot with its pinned path version. |
| vendor/vercel-openapi/openapi-<download-date>.json and SOURCE.md | Store the unmodified official JSON, source URL, download date, SHA-256, and operation count. Snapshot date/hash/count must come from the actual file. |
| scripts/openapi-find.mjs | Bounded lookup by operation words; prints method, path, summary, and parameters in at most 20 lines. |
| scripts/openapi-diff.mjs | Reports added/removed/changed operations between two snapshots. |
| test/helpers/openapi-validate.js | Validates operation existence and recorded path/query/body shapes using pinned AJV. |
| src/db.js | Keep all SQL here. Add only request-key result lookup/storage helpers required for A9 if needed; no schema migration. A write replay result must already be safely shaped before storage; never persist raw provider output that might contain secrets. |

Client behavior: inject the team ID as teamId; enforce a 25-second timeout; validate every request against the snapshot; retry GET/HEAD/DELETE once on network error or 5xx; never auto-retry POST/PUT/PATCH; translate 429 into rate_limited and retry a read only once when reset is within five seconds. A request key is stable across retries and excludes dryRun, confirm, fields, and detail; a caller-provided requestKey overrides it. Repeated keys within ten minutes return the safely stored result without another provider call. Pagination stops at its configured cap and reports capped.
