# O-5 — Admin overview, reviews and the guided-settings map

Status: implemented in this PR. Batch O card 5 of 5 (design: docs/designs/BATCH-O.md §2 O-5, decisions O7/O8; dossier: batch-o-dossier-2026-10-30.md §O-5).

## Scope

- `vercel_admin_overview` — one composed view: team profile + plan, members (count, Owners, pending invites), tokens (expiring ≤14 days, leaked), security (SAML configured/enforced, default SSO protection), domains expiring ≤30 days, certificates expiring ≤30 days + auto-renew-off count, this period's spend vs the monthly target, integrations, webhooks, drains, protected resources, and every guided setting's state. Each section is `ok`, `needs_attention` (with the reason) or `not_readable` (the read failed — the failure class is named — or no API exists).
- `vercel_admin_review_security` — Owners (a single Owner is flagged: no backup), member two-step status, SAML state, token hygiene (leaked, expiring, no-expiry, older than a year), default protection. **Member two-step is honestly `not_readable`**: the pinned member contract carries no two-step field, so the review says so and points at the guide instead of inventing a value.
- `vercel_admin_cost_review` — the O-4 charge window ranked by service and project, paid seats priced from the roster at the stored seat price (O-2; SECURITY's unknown price is reported as the owner's open question, IN-08), and the commitments count. IN-12: reads and stored defaults only.
- `vercel_admin_list_guided_settings` + `vercel_admin_check_setting`, and the `vercel_where_is_setting` upgrade — `src/data/dashboard-map.js` grows from 7 free-text guides to 25 entries in the contract §11 structured form: `{setting, url, steps: [{n, action, target, value?}], expected, verifyWith?: {tool, args, field, equals}}`, covering team, per-project and account settings pages. Deletion entries (team, project, account) are steps-only and carry no verifyWith. `check_setting` executes the entry's verifyWith against the real provider read and reports the field's current value; a guided setting is never reported done from anything but that read-back or the owner's word.
